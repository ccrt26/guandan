## 3. 实现清单（全部在 lab/，npm workspaces 之外）

| 模块 | 说明 |
|---|---|
| `lab/src/schema.ts` | 输入编码唯一权威。**state 317 维 + action 68 维 = 385 维**（v2 文稿的 389/464 为实现前设计；与实现版的差异不止"删除队友上一手块"一处——主值 4→1、贡局 4→2、级牌块 8→3 等，**推导以 §5.2 实现块表逐字段求和为准**，不以减法算术为准）。牌区=54 物理位（52 花色×点数+双王），值域 0..2（两副牌）；keyRank 归一化分母 41（rankOrder 域：普通 2..14、级牌 20+rank=22..34、小王 40、大王 41）；张数归一化分母 10（**自然同点最大 8 张，万能牌可入炸（round2 audit 实测：3 自然+1 万能=4 炸），理论上限 10 张**——分母 10 恰好覆盖，无截断）。已知限制如实记录：进贡亮明牌的归属未编码；pass 只表示选择不压。 |
| `lab/src/mlp.ts` | 纯 TS 前向（部署与采样共用）：385→256→256→1，tanh 隐层线性输出，**164,865 参数**（float32 权重文件 659,460 字节）。初始化 std=1/√fan_in（Xavier/LeCun 风格正态；**非** He 正态 √(2/fan_in)——按实现如实记录），种子确定性。 |
| `lab/src/seat.ts` | 神经席位：受限观察（只读自家手牌+公开字段白名单）+ 候选去重（键=物理计数向量+kind+mainRank+length+pairRanks）+ ε-greedy。 |
| `lab/src/sampler.ts` | 整场（match）采样：标签 y = g + W；g=本副本队名次分（赢方 +upgrade、输方 −upgrade，与引擎升级数 3/2/1 一致）、W=整场最终胜负 ±1（仅完整对局结束才赋值）；超 60 副的场丢弃并计数（本次 0 场触发）。评测跑者：固定 24 发牌种子×2 边=48 副、贪心（ε=0）、对手=中级启发式。 |
| `lab/src/bridge.ts` + `lab/learner.py` | Node↔Python 子进程二进制帧协议（1B 类型+4B 长度）。learner：PyTorch RMSprop(lr=1e-3, α=0.9, ε=1e-5, momentum=0, centered=False, wd=0) + 普通 MSE（**无 Q-clip**；梯度全局范数监控 + clip_grad_norm(1e6) 实质不裁剪 + 非有限跳步为项目配置）。每批 2048 条完成标签样本**均匀抽 1024 训一步，其余 1024 条预算弃样**（复用率 0.5，弃样计数）。 |
| `lab/src/run.ts` | 主控：bench（性能窗口）/ train（学习窗口）。训练循环：整场→标签→凑 2048→训一步→权重下一场边界换版；检查点 60/120/180 分钟（保存+评测）；到点自动停+终评。 |
| `lab/src/checks.ts` | 14 项基础验证（见 §4）。 |
| `lab/src/reload_check.ts` | 部署包重载确定性（权重文件→MLP→前向，逐位一致）。 |

**训练配置（单一固定基线，全部事前锁定）**：随机初始化（种子 20261025）；ε=0.05 恒定（合法候选内含 pass 均匀随机）；4 席全为当前模型自博弈；权重冻结边界=每场（match）；优化器/损失见上；探索 RNG=mulberry32 固定种子。

## 4. 基础验证（14/14 通过；独立复查员又独立重跑一遍）

1. schema 维度常量求和正确（317/385/164,865）；
2. MLP 同种子初始化逐位一致、异种子不同；
3. **平行世界反作弊**（领出/跟牌两种局面）：公开信息相同、对手暗牌整体替换 → 特征向量逐位一致 + 决策一致；
4. 引擎整场循环冒烟：3 场全过 A（共 33 副，场均 11 副），进贡第 2 副起出现；
5. 随机场采样冒烟：y∈[-4,4] 全在理论范围；
6. 评测跑者冒烟；
7. **启发式档位调查**（附带发现）：同一局面、同一记牌器、关噪声，中级 vs 高级能力矩阵打分 → **183 个真实决策点中 13.7% 首选不同**——档位开关真实生效；历史"三档胜率差 ≤3pp"另有原因（该旧结论原始日志未存档，已作废）。
8. 部署重载：权重文件回读前向**逐位一致（diff=0）**。

## 6. 学习窗口实测（228.1 分钟，预算 230）

**总量**：8,875 场 / 102,006 副（场均 11.49 副）/ 14,718,065 决策样本（=完成标签样本；其中 7,186×2048=14,716,928 进入分组，**尾部残留 1,137 条不足一组、未训练未保存、如实计数**）/ 7,358,464 实际训练样本（=7,186×1024 精确吻合）/ 主动弃样 7,358,464 / 7,186 更新 / **0 非有限 / 0 弃场 / 0 越界**。吞吐 26,836 副/小时、387 万样本/小时。

**评测轨迹（vs 中级启发式，24 种子×2 边=48 副，贪心）**：

| 时点 | 胜 | 胜率 | gSum（分差和） |
|---|---|---|---|
| init（随机初始化） | **0/48** | 0% | -143 |
| 60min | 21/48 | 43.8% | -16 |
| 120min | 20/48 | 41.7% | -16 |
| 180min | 26/48 | 54.2% | +1 |
| 228min（final） | 20/48 | 41.7% | -21 |

- **配对同种子 vs 初始**：20 胜 0 负 28 同（McNemar 精确 p≈1.9e-6；**注意**：该值按 48 个独立不一致配对计算，实际存在 seed 块结构（24 种子×2 边），未按种子重算——学习方向有力的证据，但 p 值应视为参考）——"显著强于随机初始"成立，学习真实。
- final 的 Wilson 95%CI = **[28.8%, 55.7%]**（忽略 seed 块内相关的参考区间）：单副口径下与中级互有胜负，**不能宣称达到或超过中级**（round2 整场口径复评修正了这一判断，见后记）。
- 对高级启发式：4/16（小样本表现偏弱，**差距大小尚未可靠估计**）。
- loss：首批 5.13 → 末批 3.80（前 500 批均值 5.37 → 后 500 批 4.03），缓慢下降、噪声大。
- 动作分布（训练全程含 ε）：单张 45.2%、pass 42.1%、炸弹 9.6%、其余 <3%。炸弹偏好明显（自博弈内炸弹换节奏可能确实赢，但对启发式是否过炸未分析）。
- 检查点波动大（43.8→41.7→54.2→41.7），**在旧的小型单副题库上波动，尚无稳定提升证据，是否平台期待确认**（round2 已用全新整场种子复评修正，见文末后记）。
