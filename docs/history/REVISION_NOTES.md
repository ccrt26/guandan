## 8. 学习窗口最终结果（2026-10-26 04:21 收盘，独立复查已通过）

- 运行 228.1 分钟（预算 230）；8,875 场 / 102,006 副 / 1,471.8 万决策样本（全部完成标签，0 弃场）/ 7,186 更新 / 0 非有限 / 0 越界；吞吐 26,836 副/小时、387 万样本/小时；内存峰值 ~767MB。
- 评测轨迹（对中级启发式，24 发牌种子×2 边=48 副，贪心）：init **0/48** → 60min 21/48 → 120min 20/48 → 180min 26/48 → 228min **20/48（41.7%，Wilson 95%CI [28.8%, 55.7%]）**。
- 配对同种子 vs 初始模型：**20 胜 0 负 28 同**（McNemar p≈1.9e-6）——"显著强于随机初始"成立。
- 对高级启发式 4/16（CI 宽，仅"无优势"）。
