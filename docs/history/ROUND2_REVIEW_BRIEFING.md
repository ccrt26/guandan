## 8. 复盘链路升级方案（请一并审核）

### 8.1 背景与问题

项目已有完整的复盘链路：GameRecord → 确定性重放 → analyzeGame 每手打分 → coach.ts 生成"牌张剧本"喂 GLM-5.3（含反幻觉铁律：只能原样引用剧本的牌）→ GLM 输出带 [[MOVE:N]] 占位符的讲解 → 前端 TrickRecap 复现卡（本轮各家牌面/你的动作高亮/引擎建议金框/回放跳转）。反事实重演（runCounterfactual：用真实手牌平行重演"如果出另一手"）已建成。

问题：**打分和建议目前来自启发式（scoreCandidates）**。本地训练的神经网络（armA_end，整场对中级 66.5%）牌力已超过启发式，但复盘没有用到它。同时存在概念疑问：GLM 是通用大模型、掼蛋牌力有限，凭什么给用户复盘？

### 8.2 我们的设计：三角色分工（教练不必比运动员跑得快）

| 角色 | 职责 | 承担者 |
|---|---|---|
| 记录员 | 还原发生了什么 | 规则引擎（重放，100% 精确） |
| 裁判 | 判断这手好不好 | **神经网络（升级后）**，替代启发式打分 |
| 解说员 | 把判断讲成人话 | GLM-5.3（引用事实 + 教学） |

核心原则：**压缩 GLM 即兴发挥的空间，增加可引用的硬事实**。GLM 不需要比训练后的 AI"懂牌"，它需要读懂记录、引用专家判断、会讲课。神经网络知道"怎么打"但说不出"为什么"（16 万参数不会说话），两者是互补不是竞争。

### 8.3 具体改动（复用现有管线，属于小改造）

1. **裁判换血**：analyzeGame 的建议/打分来源从 scoreCandidates 换为 armA_end 权重（受限适配层走 NeuralSeat，schema/TS 前向已部署就绪，weights.f32 直接加载）；启发式保留为第二意见（可选展示）；
2. **剧本加料**：每个关键手给 GLM 的剧本新增——候选前 3 名及神经评分、用户所选动作的评分与排名、分差、反事实重演结果对比（"换神经网络首选的话，实际走向是……"）；
3. **呈现分层**：硬事实（评分/排名/反事实结果）与 GLM 解读在 UI 上视觉区分；GLM 提示词加铁律"评分与重演结果只能引用剧本数字，不得自创；解读须以'我的理解是'类措辞与事实区分"；
4. **分歧与不确定标注**：用户选择 = 网络首选 → 正常讲；不一致 → 高亮分歧 + 反事实证据；网络前两名分差很小 → 标注"两可"，避免过度自信的批评。

### 8.4 我们自己看到的坑（请外部把关）

- **事后合理化**：GLM 解释网络评分的"为什么"本质是推测（网络自己也不知道为什么）——分层呈现 + 措辞约束能缓解，但不能消除；教来讲课够用，学术上不严谨；
- **评分语义**：网络输出是相对训练目标的评分，不能当"胜率"讲给用户（方案：只展示排名与分差，不展示裸分数，不出现百分比）；
- **单线反事实**：runCounterfactual 是确定性单线重演（对手后续回应按实际记录的手牌走），不是期望值——单线结果可能误导（运气成分）；缓解：关键手可重演 2-3 条变体线或明示"单线参考"；
- **训练成本为零的主张**：本方案不训练任何新模型，全部是接线工作；训练复盘专用模型（需要"局面+讲解"成对数据，只能靠 GLM 蒸馏）我们认为不划算——请外部评估这个判断。
