# 掼蛋AI训练方案与结果公开摘要

2026年10月30日，Asia/Shanghai。覆盖REVIEW6.2的原执行方案及P1至P13实际结果。训练已经停止，没有正式验收合格的新AI，网页仍使用旧模型，未部署。本摘要不包含原始牌局、教学题面、封存答案、权重或内部逐步运行日志。

## 目标与执行方案

目标是训练更会配合的本地小网络：根据队友、余牌、炸弹和局面变化做选择，最后用独立题目和完整比赛验证。

采用分阶段本地训练，不以72混合资源小时总上限或先有100条强标签作为探索开训门。合法人工/LLM建议可作为低权重弱教学；强证据和正式考试保留各自要求。初轮对照与教学臂共用起点、种子和开发配置；后续按阶段诊断，保留失败版本，不把工程检查当牌力。

最终原定验收包括60个来源家族75根、总体至少51/60及四类分别达标、严重24家族，以及完整比赛相对旧版的合作增益和分组胜率门。当前不能因缺题缩小分母或把开发比赛代替正式验收。

## 训练方式

使用本地399维小MLP，状态331维、动作68维；起点从旧模型迁移，旧网页完整政策另作产品对照。团队目标保留“本副结果＋最终完整比赛胜负”，成熟训练样本才进入对应更新。

教学偏好项按根归一，强/弱权重1/.25，偏好系数.1、margin .16，原U0锚定系数.01。P2将学习率.001降至.0001；P4起由softplus改平方hinge。此后主要围绕教学覆盖、搭档分布、剂量及锚输入覆盖做分阶段对照。弱建议一致率不是正确率，训练题命中也不是未见考试成绩。

## 最终模型的完整比赛

合作指新旧AI分别搭配相同固定伙伴的成绩差；M1为两新对两旧；M2为新AI搭固定规则伙伴对旧AI搭同一规则伙伴；S为M1/M2均值。这里没有合格真人打法代理。

| 指标 | P13 | P12 | 同进度无资源控制 |
|---|---:|---:|---:|
| 合作相对旧版 | 0.00pp | +0.52pp | +2.08pp |
| M1 | 48.44% | 43.75% | 59.38% |
| M2 | 59.38% | 60.94% | 60.94% |
| S | 53.91% | 52.34% | 60.16% |

对32个基础块直接配对后的单项97.5%描述区间，P13相对P12的M1差+4.69pp，区间[-12.50,+21.88]pp；相对无资源控制为-10.94pp，区间[-26.56,+3.13]pp。合作差分别-0.52pp、-2.08pp，区间亦跨0。不能称稳定变强，也不能从跨0推等效或无害。

这些是重复使用开发来源、单训练seed上的探索结果，不是正式盲测或跨seed复现。P13完成不等于AI升级达标；不能仅选M2偏高的结果宣称整体变强。
