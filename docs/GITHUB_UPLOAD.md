# GitHub 上传范围

本次采用干净的初始源码提交，不上传本机旧 Git 历史。本机原分支、提交、未提交工作和完整研究备份继续保留。

包含当前四个程序包、必要的网页图片/字体及许可证、运行模型、程序测试与必要测试资源、研究程序源码、依赖锁文件和文档。

不包含真实环境配置、API Key、登录凭据、个人工具配置、浏览器存档、依赖安装目录、Python 虚拟环境、构建产物、完整牌谱数据库、大型训练检查点、原始日志、实验快照及封存内容。不要通过 `git add -f` 把这些文件强制加入。

`.env.example` 只有空白配置项；使用者在本机自行创建 `.env`。模型权重属于程序资源，不是 API Key。为程序回归保留了少量模型和牌局测试资源；它们不构成完整研究数据或新能力证明。

研究源码保留原运行保护。历史研究依赖本机协议、数据路径与预算账，源码公开不代表这些任务已启动、已通过或者可以重置重跑。当前网页继续使用旧政策，未通过正式能力升级验收。
