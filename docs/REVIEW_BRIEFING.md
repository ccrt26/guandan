## 1. 用人话讲：这个"小 AI"是什么、为什么可行

- 我们的游戏已有一个"裁判"（规则引擎，保证每步出牌合法）。现在想加一个"会打牌的脑子"：一个小神经网络（几十万参数、不到 1MB 的数字文件），它看局面、给每个合法出牌打分、选最高的。**它每步只做"打分"这一件事，不联网、不调用任何大模型**。
- 训练就是调这串数字：让它自己跟自己打很多副牌，每副结束后按输赢微调参数。GLM（coding plan）的角色是**开发与解释**——写训练代码、看训练报告、诊断问题；它不是每手牌的计算者。
- **达到可用水平后可以"冻结"**：权重固定，正常玩游戏（实测：单决策端到端约 1ms、含候选枚举与编码，见 lab/out/bench_report.json），**不需要永远训练**。继续训练只是想更强时的选项，不是运行的前提。
- "继续训练必然更强"不成立；"打赢旧版高级 AI"也不等于"真人高手水平"——后者的对照需要真人数据，目前没有。

## 2. 项目硬约束（先读这个再看方案）

1. **不经用户允许不安装任何依赖**（npm/pip/brew 均在内；历史上装库被叫停过）。
2. **AI 不得作弊**：决策只准用自己手牌+公开信息；有回归测试，且 v2 追加了更细的四层一致性测试设计（TRAINING_PLAN §6）。
3. **规则口径只认《掼牌（掼蛋）竞赛规则》**：外部项目（DanZero 等）规则实现与我们不同处，一律以我们引擎为准。
4. **个人项目**：最小实现优先，不做训练平台/分布式队列/自动调参服务；优先少改现有代码。

## 4. 还没证实什么（诚实清单）

- 三个启发式档位是否真的无法拉开差距：v1 引用的"5000 副实验 ≤3pp"**原始日志未存档，不可复算**，须用新评测协议重测；启发式开关是否真实影响决策、候选裁剪是否删掉好动作，未核查。
- 我们的实际训练产能（副/日）与 learner 吞吐：全部是纸面估算，待 30-60 分钟性能试验。
- rlcard-guandan 的权重：谁训的、对应论文哪一版、规则/特征与我们引擎差异、推理是否只用可见信息——全部未验证。
- KSCB 数据：能否从事件流重建每位决策者当时的合法手牌（无进贡事件、牌码映射未说明）；许可未查。
- DanZero 论文发表 venue（Trans. on Games vs Conference on Games 2023）两处线索冲突，以一手来源为准待确认；ODMC、GuanZero 全文未取得。
- 任何训练带来的牌力提升：零。还没开始训。

## 5. 下一步怎么判断"值不值得投入"

小步试验、事前预算、看数据说话：先花 30-60 分钟测真实吞吐（生产+学习同时跑），再花 2-4 小时跑一次小学习试验看开发集曲线；有可信进步才谈追加预算，没有就先诊断（实现/目标/吞吐/探索哪个环节的问题）。**短试验无进步不证明 RL 路线无效**。最终以"完整升级对局胜率 + 独立留出评测"论英雄，不以"对自家旧 AI 赢了"自嗨。

## 6. 对 v1 简报十个开放问题的回答（逐项）

1. **产能估算乐观吗？** v1 数字有算术错误（等效核 5.2 应为 4.6；万副样本 250 万应为 156 万）。v2 已重算（TRAINING_PLAN §8），真实值待性能试验。
2. **BC 教师锁死上限？** 有此风险。BC 降为可选起点，教师按多对手评测选（含外部候选），删组合门槛，BC→DMC 切换需重新校准输出头（§7.2）。
3. **mempool 16384 的权衡？** v1"按天计陈旧"的论证在数学上不成立（百万级日产下分钟级换池）。v2 改为按策略版本滞后与复用率管理（§7.3）。
4. **纯 TS 手写 MLP 的坑？** 数学可行，但实现/维护/性能成本须诚实计入。v2 给双路线：推荐隔离 PyTorch（M4 支持 MPS GPU），零依赖备选保留小 TS 模型（§10）。
5. **ε-greedy 对 pass？** 合法 pass 有战略意义不删除；探索日程以小对照调节，不硬编码启发式偏好（§7.3）。
6. **单网络四席位梯度问题？** v1"回报回归无梯度冲突"的说法不成立已删。v2：相对座位视角+本队标签（队友同号对手反号）+四家记忆独立（§7.1/§6）。
7. **三档单调性？** 无合格 checkpoint 时保留现有策略或承认只有两档，不包装早期模型；阈值与停止条件事前约定（§9.4）。
8. **资料遗漏？** 有：已补 rlcard-guandan（含权重）、KSCB 真人数据、OpenGuanDan/SDMC、淮安地方标准（规则交叉参照）；ODMC/GuanZero 全文仍未取得。
9. **16GB 内存风险？** v2 内存账：7 进程驻留估 <1.5GB，实测确认（§8）。
10. **"一月超高级"承诺？** 已删。改为分级预算试验（性能 30-60 分钟→学习 2-4 小时），在批准预算内观察可信进步（§8/§11）。
