# T5完整人工初始牌堆与一组资源条件题原型

范围审已确认此属主T3/T5的人工合法历史实现：不需把所有初始牌局限制在32bit PRNG像集中。原生随机轨迹和人工构造分布必须分别标记，不能拿构造题证明自然胜率。本计划不改网络、奖励、最终门或heldout分区。

1. 在当前P8两臂及其评估都结束后的串行空档，给原生发牌入口增加可选的完整初始牌堆ID输入。保留startGame现有interactiveSeats参数和默认RNG路径；输入在分牌/贡还贡前接收，必须是规范buildDeck的108实体ID双射，四家各27；重复/缺失/伪牌/越界拒收，不能注入match等级、finished、turn、剩牌数。随后由现有引擎处理贡还贡和每个applyMove。只做默认同输入轨迹等价及新增输入反例检查，不重跑全项目。
2. 新source schema完整记录每副发牌类型/seed或声明108 IDs、来源家族、全合法动作前缀和规则/代码身份。沿真实默认2级前缀演化到目标等级，再开始声明牌堆的一副；不手改等级/名次。重放必须走新真实入口，不改旧native-v1证书hash冒充兼容。先做train-only原型，不把既有train根转sealed。
3. 尝试一组同初始牌堆、两条合法烧牌路径的资源条件题。首原型固定既有14副真实prefix，核levels=[10,14]、stageTeam0、级牌10；actor3配明确H10。共用目标四3炸，mate1先头游、敌0二游。预留actor四张天然4＋四A＋H10，敌2四3＋五8＋单2＋四K；其余规范牌补全。四4只用四天然4，五4才多用H10；实际核四4压四3、五A压五8、四K压四4。贡还贡后核资源仍在；失败修完整初始输入，绝不改发牌后状态。
4. 两路径都由合法动作推进：路径A保留actor九张和敌五8＋单2，敌领四3后，比较四4与五4；路径B先合法打掉actor四A、敌五8＋单2，保留actor四4＋配、敌四K，仍由敌领四3。预期前者四4保留五A反接、后者五4出尽；这是待检验教学假设，不是预先认证答案。每条路径的真实可达/公开399/共享合法动作先核；不成立就留反例，不凑一对。
5. 若只余两活家，另一家的牌可由全部公开已出＋自手唯一反推，则按原primary/secondary两冻结profile真实续到本副结束。活席必须核为epsilon0确定性神经策略，不用烧牌脚本替代根后动作。每profile分别算D=(Lplus-Uminus)/8，主须>.02、次须>0，不平均掩盖失败。完整终止W用实际值，未终止W仅[-1,+1]；量化范围为这两固定profile的本副续打及其后所有合法完成整场结局，不保证未来终止。consumer须重执行profile动作与界，不只核轨迹合法；不能用存在好策略冒充root-only价值。
6. 一对真实根与证据成立后，才补最小consumer并用现exam条件对判据验证。完整合法候选保留，例如A可能直接选五A；未验动作仍unverified，不裁成二选一/当错。若界未充分，最多而非自动对两根各做一次固定256/128；若某profile两支均已完整y=3，差精确0，直接记本方向失败，不浪费模拟。不得按结果翻方向/补到显著。先一组原型，不把60/24或15条件对凑成同型；真实独立sealed银行另按主计划制作。

所有实际发牌来源、前缀和衍生同split登记；生成器可构完整局，提出偏好的actor/LLM只接当时自手与公开信息，不接另一分支未来或源暗手。规则/发牌/证据增量由独立子审；若审查发现必须明显偏离主目标/验收方法，先停与用户讨论。P8运行时仅准备代码补丁和计划，不热改绑定的game/deck/kernel。
