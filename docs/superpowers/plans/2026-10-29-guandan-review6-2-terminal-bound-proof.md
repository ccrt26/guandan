# T5单根完整目标界证明原型

主方案已允许同目标完整证明。学习与统计子审确认以下方向可行，但尚无真实见证；先做一个生产—消费闭环，不承诺它覆盖全部考试或保证生成耗时。

公共前提：默认head3；己方A级；队友头游、另一对手二游；自己只余一张并可合法压当前单牌；仅存对手余一张且为lastPlayer。出完取得三游，本副g=2，立即过A，完整W=+1，y=3。PASS后仍活着的lastPlayer收回牌权，领出最后一张取得三游，本副g=1；后续整场W仍未知，但任何已完成整场W∈{-1,1}，故y∈{0,2}，差至少1、归一化至少.125。

这是完整g+W定义域上对所有可能最终结果的保守界，不是只比较g；不证明PASS支80副内或任意策略有限终止，绝不生成虚假complete=true/W=+1/精确终局轨迹。若前提不满足或界不能严格超过原强门，证书拒收。

1. 用冻结U0四席及独立固定train来源队列，分批模拟原生完整match，从createMatch默认2级开始，找满足公共条件的第一个根。选择器只接VisibleRoot和自手合法候选，不接源seed/其他手牌/未来结果；没有见证只报未找到，继续其他学习，不凭空改level、牌或finished。
2. 保存从首副到该根的全部合法公开动作前缀、indexed-deal来源及首家族；由引擎重新从2级逐副发牌、自动进贡还贡、resolveLegalMove/applyMove重放，核最终公开观察SHA。前缀不包含未来动作；实际完整来源结果另留，不把它当反事实PASS结果。

所有实际采样/筛过来源以及多副native前缀的每副deal family均登记train并拒foreign，不能只登记首家族。证书重新绑定rootKey、observationSHA、actor和真实两个actionKey；重算turn、精确finished顺序、两活人各1张、lastPlayer仍活着、lastCombo为single及默认规则，不能只相信元数据声明。
3. 新证据型别full-target-interval-bound-v1，保存前提、规则/引擎身份、native前缀引用、plus精确终止证据、minus仅本副已结束事实及W值域、保守差值。由consumer重新计算，不信任equivalent:true或手填上下界。
4. 原rollout证书256/128消费分支不改。先仅支持单根单pair证明，强1、root_action，只有train进入梯度；proof字段必须完整穿过卡合并与训练验收。混合/缺件拒收，不能把证明扩成全动作正确。
5. 先找一个真实train见证并完成合法卡导入，反例验证错误A级/名次/规则/前缀篡改被拒。只做当前变更的局部检查，不重跑旧先导或全套。此原型不直接混入P5，后续课程另审。

来源控制器与其他索引写入任务串行、现有单写锁/4h承接适用。先按16个固定来源一批，逐批记录是否找到和真实成本；稀少时可以按新理由改合法来源生成，但不靠无限模拟凑出结论。窄收官原型不能填资源炸弹配额、15条件对，或把60/24都做成同型容易题。
